- **🌐 เว็บไซต์จริง (Production URL):** [https://swanhill.web.app/](https://swanhill.web.app/)
- **📦 GitHub Repository:** [https://github.com/mrkoonking-debug/Swan-HILL.git](https://github.com/mrkoonking-debug/Swan-HILL.git)

## ✨ ฟังก์ชันหลักของระบบ (Core Features)

### 1. ผังบ้านพัก & จัดการสถานะห้อง (Room Dashboard)
- แสดงสถานะบ้านพักทุกหลังแบบเรียลไทม์ (ว่างพร้อมขาย / มีคนพัก / รอแม่บ้านทำความสะอาด / ปิดซ่อม)
- สลับสถานะ เช็คอิน เช็คเอาท์ และเปิดห้องว่างได้ในคลิกเดียว
- แสดงชื่อลูกค้า เบอร์โทร และสามารถแตะเพื่อโทรออกได้ทันทีบนมือถือ

### 2. ปฏิทินตรวจเช็คห้องว่าง (Mobile-First Daily & Gantt Calendar)
- **โหมดดูรายวัน (Daily View):** ออกแบบพิเศษสำหรับมือถือ แตะเลือกวันได้ด้วยนิ้วโป้ง เห็นสถานะทุกห้องในวันนั้นทันทีโดยไม่ต้องเลื่อนตารางแนวนอน
- **โหมดผังตาราง 14 วัน (Gantt Chart):** ผังภาพรวมการจองแนวนอนสำหรับเปิดดูบนคอมพิวเตอร์หรือแท็บเล็ต

### 3. ระบบจัดการรายการจอง & ถังขยะ 2 ชั้น (Bookings & 2-Stage Trash System)
- แถบเคาน์เตอร์สถิติสรุปสถานะการจอง (ทั้งหมด, กำลังพัก, รอเช็คอิน, ชำระครบ, ถังขยะ)
- การ์ดรายการจองแบบพรีเมียม พร้อมโลโก้เวกเตอร์บ้านพัก, รหัสจอง, แถบไทม์ไลน์การเข้าพัก และยอดชำระ
- **ระบบถังขยะ (Trash & Restore):** รายการจองที่ยกเลิกจะถูกย้ายเข้าถังขยะ สามารถกู้คืนได้ และมีระบบลบถาวรอัตโนมัติเมื่อครบ 15 วัน

### 4. รายงานยอดเงินและรายรับ (Financial Analytics)
- สรุปยอดเงินและจำนวนห้องพักแยกตาม **รายวัน (วันนี้)**, **รายเดือน (เดือนนี้)**, และ **รายปี (2569)**

### 5. แถบเมนูล่างแบบแคปซูลลอย (Floating Capsule Bottom Bar)
- แถบเมนูด้านล่างบนมือถือ ใช้งานง่ายด้วยนิ้วโป้ง พร้อมปุ่มกลม `+` ขนาดใหญ่ตรงกลางสำหรับกดสร้างการจองใหม่ได้ทันที

### 6. ปุ่มรีแคชข้อมูล (Clear Cache / Hard Reload)
- ปุ่มรีแคชที่มุมขวาบน สำหรับกดล้างแคชเบราว์เซอร์และดึงเวอร์ชันล่าสุดในคลิกเดียว (เทียบเท่า Ctrl+Shift+R)
